# Bezhaev agent skills (Grok · Codex · Kimi)

Skills for building **gesture / attention / spatial** interactions on web and edge.

| Skill | Agents | Role |
|-------|--------|------|
| `gesture-path-control` | Grok, Codex, Kimi | Browser hand nav for horizontal Path site |
| `mediapipe-hands` | Grok, Codex, Kimi | Hands landmarks foundation |
| `webgazer-attention` | Grok, Codex, Kimi | Gaze UX |
| `ruview-spatial-sensing` | Grok, Codex, Kimi | WiFi CSI / RuView hardware path |

## Install (Grok)
Copy folder into `~/.grok/skills/<name>/SKILL.md`

## Install (Codex)
Copy into `$CODEX_HOME/skills/<name>/`

## Install (Kimi / Claude-compatible)
Copy `SKILL.md` into project skills or agent skills directory.
